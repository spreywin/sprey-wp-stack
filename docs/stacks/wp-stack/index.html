STACK · V1.0

Sprey WP Stack

A compact, production-oriented WordPress and WooCommerce deployment for a modest VPS. Caddy is the only public service; WordPress, MariaDB and optional phpMyAdmin remain behind Docker networking.

ARCHITECTURE

A website stack, not a server control panel.

On a primary network error, timeout, or selected 5xx response, the Worker serves sprey-outage.pages.dev. No CloudPanel, Webmin or Portainer is required. phpMyAdmin is disabled by default and binds only to localhost when its optional profile is started.

QUICK START

Fresh Ubuntu or Debian VPS.

Point DNS to the VPS, clone the repository and run the installer. It installs Docker when required, generates database credentials, configures UFW, enables the resource helper and starts the stack.

terminal
git clone https://github.com/spreywin/sprey-wp-stack.git
cd sprey-wp-stack
sudo ./install.sh example.com admin@example.com

BTCPAY SERVER

WooCommerce integration.

V1.0 uses the current BTCPay for WooCommerce V2 integration. The BTCPay Server itself is separate infrastructure; this stack hosts the WooCommerce side of the integration. Detailed connection steps live in the shared Sprey Docs portal.

CLOUDFLARE · V1.0

Free request-time failover.

Production uses Full (strict) TLS and avoids caching dynamic WooCommerce routes. A Workers Route tries the primary WordPress VPS on every request and serves sprey-outage.pages.dev after a network error, timeout, or selected 502/503/504. Primary returns automatically on the next successful request. This is not periodic health monitoring, and the fallback cannot provide cart, account, checkout, order, or payment functionality.

OPERATIONS

See resource pressure before it becomes downtime.

VPS + containers

./status.sh

Detailed disk

docker system df -v

Logs

docker compose logs -f caddy

Container logging is bounded with Docker's local driver: 10 MB per file and up to 3 files per container.

Back up MariaDB and WordPress uploads before upgrades. Never run docker compose down -v on a production deployment.
