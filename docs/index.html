SPREY WP STACK

WordPress infrastructure without a server panel.

A lightweight, production-oriented Docker Compose stack for WordPress and WooCommerce with Caddy, MariaDB, optional local-only phpMyAdmin, operational safeguards, and a clean path to BTCPay Server integration.

QUICK START

From a clean VPS to WordPress.

The installer prepares Docker when needed, creates private credentials, preserves the active SSH port while configuring UFW, starts the stack, and enables the resource status helper.

terminal
git clone https://github.com/spreywin/sprey-wp-stack.git
cd sprey-wp-stack
sudo ./install.sh example.com admin@example.com

LOG SAFETY

Container logs are bounded by default.

01

Local driver

The stack uses Docker's local logging driver instead of allowing unbounded default log growth.

02

10 MB per file

Each container log file is capped at 10 MB.

03

Three files

Rotation keeps at most three files per container, preventing logs from silently consuming the whole VPS disk.

PAYMENTS & RESILIENCE

WooCommerce, BTCPay and Cloudflare stay loosely coupled.

BTCPay Server remains separate from the WordPress stack. WooCommerce connects through the current BTCPay integration. The v1 design also keeps a static Cloudflare Pages outage fallback separate from the live WooCommerce origin.
