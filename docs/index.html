PRODUCTS

Sprey services.

01

Sprey Processing

Self-hosted crypto payment infrastructure built around BTCPay Server. Customer funds remain under customer control; Sprey provides infrastructure and automation.

Payment host: pay.sprey.win

02

Sprey RPC

Planned RPC/eRPC gateway for stable access to TRON and EVM networks, with API keys, availability monitoring and plan-based billing.

Planned: rpc.sprey.win

03

Sprey VPN

Planned privacy service with isolated traffic nodes and automated crypto billing. VPN nodes remain separate from payment and web infrastructure.
